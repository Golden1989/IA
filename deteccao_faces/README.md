# 🕵️‍♀️ Detecção de Faces com OpenCV

Este projeto faz parte do meu TCC e tem como objetivo detectar faces em imagens usando o classificador Haar Cascade do OpenCV.

## 📌 Sobre o Projeto

O sistema carrega imagens de uma pasta, detecta rostos utilizando o modelo pré-treinado `haarcascade_frontalface_default.xml` e exibe as imagens com as faces demarcadas por retângulos verdes.

## 🛠️ Tecnologias Utilizadas

- Python 3.12
- OpenCV (cv2)
- Matplotlib
